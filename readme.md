StudentCard is an interactive web application engineered with React for designing, customizing, and managing digital student identity credentials with real-time 3D card previewing, barcode rendering, and offline local persistence.

---

## 🌟 Key Features

- **🔄 3D Flippable Smart ID Card**: Tactile 3D perspective card supporting live rotation between:
  - **Front Face**: High-resolution avatar photo, student name, academic programme, unique matriculation ID, validity dates, and semester badge.
  - **Back Face**: High-density scannable barcode, institutional return address, emergency telephone line, and official registrar validation notice.
- **⚡ Real-Time WYSIWYG Editing**: Every character typed into the registration form instantly renders on the live preview card with smooth transition physics.
- **🎨 Faculty Color-Coding**: Dynamic department thematic accents (Computer Science, Business Administration, Engineering, Natural Sciences, Fine Arts).
- **📋 Roster Management & Instant Search**: Searchable student card grid with multi-attribute filtering by student name, roll number, or enrollment status.
- **⏳ Expiration Verification**: Automatically detects expired credentials, displaying an amber warning badge and formatted typography.
- **💾 Offline-First Local Storage**: All student records, edited attributes, and custom credentials persist reliably in browser storage.

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** (v9.0.0 or higher)

### Installation

1. **Clone the repository:**
   \\\ash
   git clone https://github.com/yvb-t/STUDENT-CARD-SYSTEM.git
   cd STUDENT-CARD-SYSTEM
   \\\

2. **Install dependencies:**
   \\\ash
   npm install
   \\\

3. **Start local development server:**
   \\\ash
   npm run dev
   \\\
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build production bundle:**
   \\\ash
   npm run build
   \\\
